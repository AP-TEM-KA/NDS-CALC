# 🧮 Калькулятор НДС и налогов сделки

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Online-brightgreen)](https://ap-tem-ka.github.io/NDS-CALC/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Инструмент для расчета налогов, НДС и прибыли при сделках купли-продажи. Помогает бизнесу быстро оценить финансовые результаты сделки.

## ✨ Возможности

- ✅ Расчет входящего и исходящего НДС
- ✅ Учет налога на прибыль (20%)
- ✅ Сохранение истории расчетов
- ✅ Темная/светлая тема (автоматическая)
- ✅ Настройка налоговых ставок
- ✅ Округление результатов
- ✅ Адаптивный дизайн для всех устройств
- ✅ Работает полностью в браузере

## 🚀 Быстрый старт

1. Откройте [калькулятор онлайн](https://ap-tem-ka.github.io/NDS-CALC/)
2. Введите сумму покупки товара/услуги
3. Введите сумму продажи
4. Настройте налоговые ставки при необходимости
5. Получите детальный расчет прибыли и налогов

## 📱 Интерфейс

### Вкладки:
- **Покупка** - ввод суммы закупки
- **Продажа** - ввод суммы реализации
- **Итог** - результаты расчета с визуализацией
- **Настройки** - настройка налоговых ставок
- **История** - история предыдущих расчетов

## 🛠 Технологии

- **React 18** - UI библиотека
- **Tailwind CSS** - стилизация
- **Font Awesome** - иконки
- **Babel Standalone** - компиляция JSX в браузере
- **LocalStorage API** - сохранение настроек и истории

## 📊 Что рассчитывает калькулятор?

1. **Входящий НДС** - НДС, который вы платите поставщику
2. **Исходящий НДС** - НДС, который вы начисляете клиенту
3. **НДС к уплате** - разница между исходящим и входящим НДС
4. **Налог на прибыль** - 20% от разницы между выручкой и затратами
5. **Чистая прибыль** - прибыль после всех налогов
6. **Маржинальность** - рентабельность сделки в процентах

## 🔧 Настройки

- Ставка НДС при покупке (0%, 10%, 20%, 22%)
- Ставка НДС при продаже (0%, 10%, 20%, 22%)
- Ставка налога на прибыль (по умолчанию 20%)
- Округление результатов (математическое, вверх, вниз)

## 💾 Сохранение данных

- Настройки сохраняются автоматически
- История до 50 последних расчетов
- Тема (темная/светлая) сохраняется
